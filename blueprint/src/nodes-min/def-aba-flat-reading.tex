\begin{definition}[The flat reading of a protocol]
  \label{def:aba-flat-reading}
  \lean{PLTS.ABA.Net.NetEvtP}\lean{PLTS.ABA.Net.actsAt}\lean{PLTS.ABA.Net.wccPull}\lean{PLTS.ABA.Net.StageSideRecP}\lean{PLTS.ABA.Net.StageRecord}\lean{PLTS.ABA.Net.NetStateP}\lean{PLTS.ABA.Net.roundOf}\lean{PLTS.ABA.Net.NetStateP.writeGhost}\lean{PLTS.ABA.Net.stageOwn}\lean{PLTS.ABA.Net.FlatProcStep}\lean{PLTS.ABA.Net.FlatNetStep}\lean{PLTS.ABA.Net.IsStageTable}\lean{PLTS.ABA.Net.flat}\leanok
  \uses{def:aba-labels, def:aba-params, def:aba-core-vocab, def:relabel, def:syncproduct, def:process-algebra, def:idle-family}
  A protocol as it runs: $n$ programs, one per process, beside one network adversary holding the message sets, the DECIDED sets and the corrupted set with its budget, beside the coin oracle.
  The reading is parametric in the graded-agreement implementation --- its message type, its per-process per-round stage record, and its rows --- so the round loop, the DECIDED sets, the coin handshake, corruption, the adversary and the composition pipeline are written once: \leandecl{PLTS.ABA.Net.flat}.
  It is parametric in one thing more, a per-round ghost record the adversary holds, with an update \leandecl{PLTS.ABA.Net.NetStateP.writeGhost} applied on every row and an output relating the adversary's state, the round, the process answered, the graded outcome and a bit, which guards the two graded-agreement return rows (D30).
  A reading supplies four things about its own rows, and the lemmas that read a row off its label consume them: that a row of process $j$ carries a label of $\mathrm{stageOwn}(j)$, that it fires only at an unreplaced program (D23), that it is Dirac, and that a return row takes the announced bit free, firing at every other bit with the same successor (D29): \leandecl{PLTS.ABA.Net.IsStageTable}.
\end{definition}
