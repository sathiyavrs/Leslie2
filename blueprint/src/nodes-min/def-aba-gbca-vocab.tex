\begin{definition}[Stage messages and the stage record]
  \label{def:aba-gbca-vocab}
  \lean{PLTS.ABA.GBCA.ByABDY.Message}\lean{PLTS.ABA.GBCA.ByABDY.ProcessRecord}\leanok
  The messages of one graded-agreement stage run over five message levels, and the stage state of one process is a record holding its call payload, its write-once send fields and its return flag, no field of which names another process: \leandecl{PLTS.ABA.GBCA.ByABDY.Message} and \leandecl{PLTS.ABA.GBCA.ByABDY.ProcessRecord}.
\end{definition}
