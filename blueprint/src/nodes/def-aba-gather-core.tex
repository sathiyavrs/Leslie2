\begin{definition}[The core of a gather network state]
  \label{def:aba-gather-core}
  \lean{PLTS.ABA.Gather.correct}\lean{PLTS.ABA.Gather.dominatedBy}\lean{PLTS.ABA.Gather.dominators}\lean{PLTS.ABA.Gather.echoOf}\lean{PLTS.ABA.Gather.coreOf}\lean{PLTS.ABA.Gather.Invariant}\lean{PLTS.ABA.Gather.single_core}\lean{PLTS.ABA.Gather.single_core_approved}\lean{PLTS.ABA.Gather.withoutBindAbove}\lean{PLTS.ABA.Gather.coreOf_recorded}\leanok
  \uses{def:aba-gather-over-broadcast-specification, def:aba-parameters}
  The core of the instance of Definition~\ref{def:aba-gather-over-broadcast-specification} is a payload set read off one network state, and the size bound the core transition of Definition~\ref{def:aba-gather-spec} requires is a theorem about it.
  Write $w$ for a gather network state, that is, the per-sender sent sets beside the corrupted set.
  Let $\mathrm{correct}(w) = [n] \setminus F$, let
  \[
    \mathrm{dominatedBy}(w, q) \;=\;
      \{\, j \;:\; \text{every } \mathrm{VOTE} \text{ of } q
      \text{ lies above an } \mathrm{ECHO} \text{ of } j \,\},
  \]
  and let $\mathrm{dominators}(w, j)$ be the processes of $\mathrm{correct}(w)$ whose every $\mathrm{VOTE}$ payload lies above an $\mathrm{ECHO}$ payload of $j$.
  The condition holds of every $j$ at a $q$ that has multicast no $\mathrm{VOTE}$, so $\mathrm{dominatedBy}(w, q)$ is then everything.
  Let $\mathrm{echoOf}(w, j)$ be the $\mathrm{ECHO}$ payload $j$ has multicast, and $\emptyset$ where it has multicast none.
  The core $\mathrm{coreOf}(P, w)$ is $\mathrm{echoOf}(w, j)$ at some $j \in \mathrm{correct}(w)$ with $f + 1 \le |\mathrm{dominators}(w, j)|$, and $\emptyset$ where no such $j$ exists.
  Such a $j$ exists.
  A $\mathrm{VOTE}$ of a process outside $F$ is backed by $n - f$ received $\mathrm{ECHO}$ messages, each contained in it, so $n - f \le |\mathrm{dominatedBy}(w, q)|$ for every $q$ outside $F$, one that has multicast no $\mathrm{VOTE}$ included.
  Summing that bound over the senders outside $F$ and exchanging the order of summation gives a sender $j_0$ outside $F$ with
  \[
    n - f - |F| \;\le\; |\mathrm{dominators}(w, j_0)|,
  \]
  and $n - f - |F| \ge f + 1$ at $3f < n$ and $|F| \le f$.
  The invariant \leandecl{PLTS.ABA.Gather.Invariant} ties a correct sender's sent messages to its write-once fields and those fields to the quorums of received messages behind them, and adds one clause, $echo\_approved$: every entry in any process's $\mathrm{ECHO}$ field is a committed input-broadcast entry.
  Under it, once one process outside $F$ has multicast a $\mathrm{BIND}$ payload, the core has at least $n - f$ entries, its entries are committed input-broadcast entries, and it lies below every $\mathrm{BIND}$ payload in the sent set of a process outside $F$.\lean{PLTS.ABA.Gather.single_core}\lean{PLTS.ABA.Gather.single_core_approved}\leanok{} That the core lies below such a payload $U$ is the transfer: the $f{+}1$ dominators of the sender the core comes from meet the $n - f$ $\mathrm{VOTE}$ quorum backing $U$, and the meeting process's write-once $\mathrm{VOTE}$ payload lies above the core and below $U$.
  The size bound is the $\mathrm{ECHO}$ payload's own, a correct sender sending $n - f$ entries in it.
  The witness that holds the returns after the first to the core $C$ that first return writes is the set
  \[
    \mathrm{withoutBindAbove}(s, C) \;=\;
      \{\, d \notin F \;:\; \text{no } \mathrm{BIND} \text{ payload } U \in \mathit{sent}(d)
      \text{ with } C \subseteq U \,\}.
  \]
  At the first return it has at most $f$ members: the returner has received $\mathrm{BIND}$ payloads from $n - f$ senders, and each of them outside $F$ has sent one containing $C$.\lean{PLTS.ABA.Gather.coreOf_recorded}\leanok{}
  Along every transition and every corruption $F$ and every sent set only grow, so the set only loses members.
  At a later return, the $n - f$ senders of the returner's received $\mathrm{BIND}$ payloads include at least $n - 3f \ge 1$ processes outside $F$ and outside the set.
  Such a process has a single $\mathrm{BIND}$ payload in its sent set, so the payload received from it contains $C$.
\end{definition}
