\begin{definition}[The two-gather round]
  \label{def:aba-gbca-pair}
  \lean{PLTS.ABA.GBCA.cand}\lean{PLTS.ABA.GBCA.gradeOf}\lean{PLTS.ABA.GBCA.boundOfCore}\lean{PLTS.ABA.GBCA.PairState}\lean{PLTS.ABA.GBCA.PairStep}\lean{PLTS.ABA.GBCA.pairInst}\leanok
  \uses{def:aba-gather-spec, def:aba-gbca-spec, def:aba-labels}
  The graded agreement of~\cite{AFW25} --- its Algorithm~4 at $R = 2$, the two-gather branch, with the grade read off the second gather's counts in place of the approximate-agreement subroutine of lines~7 and~8 (D24) --- over two gather specification instances of Definition~\ref{def:aba-gather-spec}, the first at payload type $\mathbb{B}$ and the second at $\mathbb{B} \cup \{\bot\}$.
  The state is the triple of the two gather states and the round's bound bit: the round's per-process input is the first instance's $call$, the candidate the second's, and the round's return flags the second's $ret$.
  For a first-gather output $g$, the candidate is
  \[
    \mathrm{cand}(g) \;=\;
      \begin{cases}
        v & \text{if } |{\rm dom}\, g| - f \le \#\{k : g(k) = v\},\\
        \bot & \text{if neither bit qualifies,}
      \end{cases}
  \]
  at most one bit qualifying since the return domains carry $n - f > 2f$ entries; for a second-gather output $h$, the grade is $(v, A)$ at $|{\rm dom}\, h| - f$ entries of $v$, $(v, B)$ at $f + 1$, and $(\bot, C)$ below both.
  The rows embed the gather rules: the round's $\mathrm{callG}$ is the first gather's call, each gather's internal rules are $\tau$-rows of the pair, the link row fuses the first gather's return to a process with that process's call of the second gather at the candidate, the round's $\mathrm{retG}$ is the second gather's return read through the grade, and corruption is the lockstep transform of both instances (D1).
  The third factor is auxiliary state (D29): no program reads it and no guard consults it.
  The link row writes it, at the round's first link and once only, as $\mathrm{boundOfCore}$ of the core the first gather's return carries, and every graded return announces it on its label.
  For a payload set $S$, $\mathrm{boundOfCore}(S)$ is the bit heavy in $S$ --- carried by at least $|S| - f$ of its entries --- and $1$ where neither bit is.
  At the sizes the freeze of Definition~\ref{def:aba-gather-spec} allows, $|S| \ge n - f > 2f$, at most one bit is heavy, so a return handing out $v$ announces $v$ and a return handing out nothing announces a bit whose complement no return can hand out.
  Full construction: \leandecl{PLTS.ABA.GBCA.pairInst}.
\end{definition}
