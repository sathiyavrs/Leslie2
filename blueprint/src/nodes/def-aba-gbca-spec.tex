\begin{definition}[The graded-agreement specification]
  \label{def:aba-gbca-spec}
  \lean{PLTS.ABA.GBCA.Step}\lean{PLTS.ABA.GBCA.specFamily}\leanok
  \uses{def:aba-labels, def:idle-family}
  Transition System 2, as a round-indexed instance and the $\mathbb{N}$-indexed family of Definition~\ref{def:idle-family} over it: internal binding and the graded returns $A\,b$, $B\,b$ and $C$. The family is an LTS.\lean{PLTS.ABA.GBCA.specFamily_isLTS}\leanok{} An instance binds by exclusion (D19): its state carries the set $excluded \subseteq \{0,1\}$ of bits the instance can no longer hand out, written only by an internal exclude enabled from $excluded = \emptyset$ alone, so the exclusion fires at most once per instance; beside it the state carries the pending call $call$ and the return flag $ret$ of each process, the grade lock $grade$, set by an $A$-return and by a $C$-return exclusively, and the corrupted set.
  That exclude, the dissenting bit at a $B$-return and each of the two bits at a $C$-return carry an $f{+}1$ $F$-blind support guard, $\mathrm{SuppOK}$: $f{+}1$ distinct callers-or-corrupted of the bit in question (D14, D15).
  Every return rule, whatever its grade, takes a bit $bnd$ under the guard $1-bnd \in excluded$ and announces it on the label $\mathrm{retG}(r,id,out,bnd)$.
  On a reachable state $excluded$ holds at most one bit, so that guard determines $bnd$ as the complement of the excluded bit and all the returns of a round announce one bit.
  A value-bearing return of $v$ carries $v \notin excluded$ and $1-v \in excluded$ as well, so it announces $bnd = v$.
  The bit is a ghost output (D29): it is the bound value the specification holds as state, and no program reads it.
  In a round that hands out no value the run ends with $C$-returns alone, and those returns announce the surviving bit, so the round is bound on the trace all the same.
  Full rule table: \leandecl{PLTS.ABA.GBCA.specFamily}.
\end{definition}
