\begin{theorem}[The gather-based composition]
  \label{thm:aba-afw-protocol-composed}
  \lean{PLTS.ABA.AFW.roundProjection}\lean{PLTS.ABA.AFW.BoundInvariant}\lean{PLTS.ABA.AFW.ProtocolRelation}\lean{PLTS.ABA.AFW.protocolSimulation}\lean{PLTS.ABA.AFW.protocol_composed}\leanok
  \uses{def:aba-afw-protocol, def:aba-afw-round-families, thm:forward-sound, def:achievable}
  The gather-based protocol is forward-simulated by its composed system, and hence every trace distribution it achieves is achieved there.
  The relation has five conjuncts: the round loops and the common coin are shared objects, the ABA network is the DECIDED sets beside the corrupted set, each round's instance is the projection $\mathrm{roundProjection}$ of the implementation's state, and every round in which a process holds a candidate holds its bound bit.
  The first four are unguarded, so they determine the composed state from the implementation's; the fifth, \leandecl{PLTS.ABA.AFW.BoundInvariant}, is the one clause that is not read off the implementation's state.
  Assembling the projection undoes the two separations between the implementation and the composed system --- the local states are transposed back out of the round variables the $n$ processes hold, and each network's sent set is projected out of the adversary's single tagged sent-set family --- and it reads the two gathers' cores and the round's bound bit off the adversary's ghost for that round.
\end{theorem}

\begin{proof}\leanok
  \uses{def:aba-afw-protocol, def:aba-afw-round-families, def:forwardsim}
  Every transition writes the acting process's round variables and records at most one tagged message, and one lemma says what that does to the projection: the round the transition names reads as the one-point update of each of its coordinates.
  What a transition then owes is sent set algebra --- which of the six projected sent sets takes the message and which are left alone --- and the projection commutes with a sent set write in exactly those two ways.
  On that basis each transition of the implementation is matched by one event of the composed round: a send and a delivery are hidden events of the round, matched by one silent step, the adversary's authenticity conjunct becoming membership in the projected sent set; the graded-agreement call is the round's own call and the second gather's call the round's event for it; a gather's return is that gather's return event; the call of a process's own input broadcast is the call event of that instance inside the gather it belongs to; and a broadcast instance's return is the event that records what it returned.
  The remaining labels never reach the implementation.
  The ABA interface, the coin's call and return, the DECIDED send and the other DECIDED transitions move the round loop and the ABA network while the family of rounds is unchanged; corruption is one broadcast, the corrupted set the adversary holds being the corrupted set of every network state under the same guard; and the two Byzantine graded-agreement transitions have no transition at the process they name.
  A program's transition on a label of $\mathrm{roundOwn}(j)$ is a transition of the implementation, which is what lets each of those cases rule the others out.
  The three fields of the round instance that no guard of it reads --- the core of each of its two gather instances and the round's bound bit --- are the adversary's ghost at the implementation, and a transition's ghost write is the instance's write of them.
  The projection of the round the transition names is the one-point update of those three coordinates, \leandecl{PLTS.ABA.AFW.roundProjection_writeGhost}; every other round's projection stands where it is, \leandecl{PLTS.ABA.AFW.roundProjection_writeGhost_ne}; and a transition whose write returns the ghost it found moves no round's projection at all, \leandecl{PLTS.ABA.AFW.roundProjection_ghostId}.
  The first gather's return writes that gather's core and the bound bit, and it is the only transition that records a candidate, so the round holds the bit a graded return announces when the return fires; the round's own return drops the recorded outcome, on either side.
\end{proof}
