\begin{theorem}[Binding of graded agreement, on a trace]
  \label{thm:aba-gbca-binding-trace}
  \lean{PLTS.ABA.GBCA.BindingTrace}\lean{PLTS.ABA.GBCA.specInst_binding}\lean{PLTS.ABA.GBCA.BindingTrace.value_agree}\lean{PLTS.ABA.GBCA.BindingTraceExtended}\lean{PLTS.ABA.GBCA.specificationOverRoundAlphabet_binding}\lean{PLTS.ABA.GBCA.ByABDY.composition_binding}\lean{PLTS.ABA.GBCA.roundOverGatherSpecifications_binding}\lean{PLTS.ABA.GBCA.roundOverBroadcastSpecification_binding}\lean{PLTS.ABA.GBCA.roundOverBracha_binding}\leanok
  \uses{def:aba-gbca-spec, thm:gbca-spec-binding, thm:trace-support, thm:forward-sound, thm:aba-gbca-composition-by-abdy-refines-specification, thm:gbca-round-refines-specification, thm:gbca-round-substitutions, thm:gbca-gather-refines}
  $\mathrm{BindingTrace}$ is the conjunction of three clauses on the round-$r$ labels of a trace: any two announcements $\mathrm{boundG}(r,\beta_1)$ and $\mathrm{boundG}(r,\beta_2)$ name the same bit; a return $\mathrm{retG}(r,id,o)$ of a value $v$ and an announcement $\mathrm{boundG}(r,\beta)$ name the same bit, $v = \beta$; and any two returns of values return the same bit.
  Every trace in the support of every achievable trace distribution of the round-$r$ GBCA specification instance satisfies $\mathrm{BindingTrace}$.\lean{PLTS.ABA.GBCA.specInst_binding}\leanok{} Graded agreement is the third clause, a consequence of the trace predicate alone.\lean{PLTS.ABA.GBCA.BindingTrace.value_agree}\leanok{}
  The announcement is enabled at every state from the round's first return on, so every trace with a return extends by an announcement, and the second clause then binds every return of a value in every extension: this is ABDY22's Graded Binding on a trace.
  The predicate is stated on the labels of a trace, so every inclusion of achievable trace distributions into the instance carries it.
  The four compositions below Transition System~2 are over the round's alphabet, the family alphabet of Definition~\ref{def:aba-programs}, so in them the predicate is read on the shared labels of that alphabet, $\mathrm{BindingTraceExtended}$, and the specification read over that alphabet satisfies it by the same argument on its own executions.\lean{PLTS.ABA.GBCA.specificationOverRoundAlphabet_binding}\leanok{}
  The direct implementation instance satisfies it along the inclusion of Theorem~\ref{thm:aba-gbca-composition-by-abdy-refines-specification}.\lean{PLTS.ABA.GBCA.ByABDY.composition_binding}\leanok{}
  The round over the gather specifications satisfies it along the counting refinement of Theorem~\ref{thm:gbca-round-refines-specification}.\lean{PLTS.ABA.GBCA.roundOverGatherSpecifications_binding}\leanok{}
  The round over the broadcast specifications satisfies it along the gather substitution of Theorem~\ref{thm:gbca-round-substitutions} chained with the counting refinement.\lean{PLTS.ABA.GBCA.roundOverBroadcastSpecification_binding}\leanok{}
  The gather-based implementation satisfies it along the chained inclusion of Theorem~\ref{thm:gbca-gather-refines}.\lean{PLTS.ABA.GBCA.roundOverBracha_binding}\leanok{}
\end{theorem}

\begin{proof}\leanok
  \uses{def:aba-gbca-spec, thm:gbca-spec-binding, thm:trace-support, thm:forward-sound, thm:aba-gbca-composition-by-abdy-refines-specification, thm:gbca-round-refines-specification, thm:gbca-round-substitutions, thm:gbca-gather-refines}
  Theorem~\ref{thm:trace-support} turns a positive-probability trace into a genuine execution of the instance in which each round-$r$ return label and each round-$r$ announcement of the trace is a step of a return transition or of the announcement at some state.
  The three clauses are then Theorem~\ref{thm:gbca-spec-binding} read at those steps: two announcements name one bit, a return of a value and an announcement name one bit, and two returns of values return one bit.
  Nothing beyond positive probability is required of the trace, and nothing beyond membership in one execution of the steps.
  This is what carries binding down a chain of refinements: the property is stated on labels, so an inclusion of achievable trace distributions carries it.
  The four statements below Transition System~2 are that argument applied to the soundness inclusion of each refinement, by Theorem~\ref{thm:forward-sound}.
\end{proof}
