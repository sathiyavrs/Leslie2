\begin{theorem}[Gather core refinement]
  \label{thm:gather-core}
  \lean{PLTS.ABA.Gather.IdealInv}\lean{PLTS.ABA.Gather.CoreRel}\lean{PLTS.ABA.Gather.gatherCore}\leanok
  \uses{def:aba-gather-ideal, def:aba-gather-spec, def:aba-gather-core}
  The gather implementation over broadcast specifications is forward-simulated by Transition System~4.
  The relation reads the specification's $call$, $ret$ and $F$ off the implementation, certifies each committed abstract entry by the corresponding input-broadcast commitment, holds the two sides' cores equal, and certifies a written core by the count
  \[
    f + 1 \le |\{\, q \;:\; \exists\, U,\ \mathit{brbBind}(q).val = U \ \text{and}\ core \subseteq U \,\}|,
  \]
  which is $F$-blind and monotone, the broadcast values being write-once.
  A return is answered by one weak run: the abstract commits for the output's entries, the write of the core where the specification holds none, then the return.
\end{theorem}

\begin{proof}\leanok
  \uses{def:aba-gather-ideal, def:aba-gather-spec, def:aba-gather-core, def:forwardsim}
  The invariant ties each honest coordinate to its process --- inputs to calls, bind inputs to the $\mathrm{BIND}$ row's quorum guard --- and carries approval-backing for the write-once $\mathrm{ECHO}$ and $\mathrm{VOTE}$ fields.
  The core written is the core of Definition~\ref{def:aba-gather-core}, read off the instance's message state, and the two guards of that write are its size bound and its approval, both supplied by the returner's own quorum of $n - f$ committed bind payloads.
  The same quorum supplies the $f{+}1$ coordinates whose committed payloads lie above the core, which is the count the relation carries.
  Every return after the first is matched through that count: it is $F$-blind and monotone, so it survives every later rule and every corruption, and the return's own $n{-}f$ quorum meets it in a coordinate whose committed payload lies above the core and below the returned map, which is what the return's $C \sqsubseteq g$ guard requires.
  Sending the $\mathrm{BIND}$ payload by reliable broadcast is what the count rests on: the count reads committed payloads, which a sender corrupted after the write cannot rewrite.
  Every internal row is answered by the matching abstract commit or by a stutter, and corruption by the specification's own $\mathrm{fail}$.
\end{proof}
