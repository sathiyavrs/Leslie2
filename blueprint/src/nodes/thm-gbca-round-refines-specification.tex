\begin{theorem}[Two-gather round refinement]
  \label{thm:gbca-round-refines-specification}
  \lean{PLTS.ABA.GBCA.count_aboveThreshold_of_subMap}\lean{PLTS.ABA.GBCA.boundOfCore_of_aboveThreshold}\lean{PLTS.ABA.GBCA.count_boundOfCore_belowThreshold}\lean{PLTS.ABA.GBCA.ByAFW.Invariant}\lean{PLTS.ABA.GBCA.ByAFW.ExclusionWitness}\lean{PLTS.ABA.GBCA.ByAFW.SpecificationRelation}\lean{PLTS.ABA.GBCA.ByAFW.refinesSpecification}\leanok
  \uses{def:aba-round-over-gather-specifications, def:aba-gbca-spec}
  The two-gather round is forward-simulated by the GBCA specification instance (Transition System~2).
  The relation takes the specification's $call$, $ret$ and $F$ from the pair and witnesses its $excluded$ and $grade$ on the two cores, each written once: a bit $b$ is excluded under
  \[
    \mathrm{ExclusionWitness}(b) \;=\; \exists\, S,\ core_1 = S \,\wedge\, \#\{(k, b) \in S\} < |S| - f,
  \]
  the grade-2 guard by the second core carrying one bit on at least $|S| - f$ entries, and the grade-0 guard by the second core carrying each bit on at most $f$; the cores being write-once, every witness stands from the moment it is written.
  Two clauses more tie the exclusion set to the round's bound bit $\mathrm{boundOfCore}(S)$ of the first core: an excluded bit is its complement, and once the round's network has recorded a return the specification excludes its complement, which is the guard of the specification's announcement.
  Exclusions fire on demand, as the weak run $\mathrm{bindUnset}; \mathrm{ret}$ under the first return that needs the exclusion.
\end{theorem}

\begin{proof}\leanok
  \uses{def:aba-round-over-gather-specifications, def:aba-gbca-spec, def:forwardsim}
  The counting is on the cores, and rests on $|S| \ge n - f > 2f$ at $3f < n$.
  A returned map carrying $x$ on all but $f$ entries makes the core the return carries do the same at $x$, the core sitting below the map up to $f$ entries (the core form of Lemma~13 of~\cite{AFW25}); a core carrying $x$ on at least $|S| - f$ entries carries no other value on that many, its shared entries admitting one value on all but $2f$ (Proposition~14 and Lemma~18, and the grade-2 / grade-0 exclusivity of the grade guard).
  A candidate $v$ arriving at the second gather is on at least $|S| - f$ entries of the first core, recorded by the invariant at the first gather's return that computed it and read again at the second gather's call, so $v$ is the bound bit $\mathrm{boundOfCore}$ names and a standing $\mathrm{ExclusionWitness}(v)$ is refuted.
  The exclusion clause leaves each of the three return transitions the same two cases: the complement of the bound bit is already excluded, and the return fires alone; or nothing is excluded, and the run $\mathrm{bindUnset}; \mathrm{ret}$ fires, its witness being that the first core counts the complement below $|S| - f$.
  A return of grade 1 or 2 returns the bound bit, by the threshold count in the first core ($v$ appears on at least $|S| - f$ of its entries), so the specification's guard pair $v \notin excluded$, $1-v \in excluded$ is the exclusion of the bound bit's complement, and the exclusion's $f{+}1$ support and the grade-1 return's dissent count are computed from the core through each committed entry being the payload its instance recorded, which is $F$-blind.
  The round's announcement of the bound bit fires once its network has recorded the first core and a return, and the specification's announcement of the same bit is enabled there, the complement being excluded from the round's first return on.
  The invariant ties each gather's committed entries to correct calls, records what the computed candidate witnesses about the first core, ties the core the round's network records to the first gather's core, and records at the second gather's return the witness the graded return consumes, since that return sees the recorded grade alone; every internal transition preserves it, and corruption is matched by the specification's own $\mathrm{fail}$ under the two corrupted sets moving together.
  Each case is obtained from a transition of the composition by its characterisation by the algorithm, and the specification's matching run is read back over the round's alphabet along a section of the projection onto the specification's labels.
\end{proof}
